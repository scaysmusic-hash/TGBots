# Telegram-бот "Рынок"

Полнофункциональный Telegram-бот, реализующий сложную систему рынка с четырьмя ролями, внутренней валютой "Звездочки" (1 ⭐ = 1 рубль), механизмом "Безопасной сделки" и системой репутации.

## 🚀 Функционал

### 1. Система ролей
Бот поддерживает 4 уровня доступа:
*   **Покупатель:** Основной пользователь, может покупать, пополнять баланс, жаловаться.
*   **Предприниматель:** Может создавать объявления, промокоды, получать повышение.
*   **Администратор:** Управляет пользователями (блокировка, смена ролей), объявлениями, рассматривает жалобы.
*   **Владелец:** Полный контроль, включая управление реквизитами, рассылку, установку цен.

### 2. Финансовая система ("Звездочки" ⭐)
*   **Пополнение:** Пользователь вводит сумму в рублях, получает расчет в "Звездочках" (1 ⭐ = 1 рубль). Отправляет скриншот оплаты, который подтверждает Администратор.
*   **Вывод:** Пользователь запрашивает вывод, Администратор обрабатывает запрос. **Комиссия за вывод: 15%**.
*   **Промокоды:** Создаются Предпринимателями для скидок.

### 3. Рынок и "Безопасная сделка"
*   **Объявления:** Предприниматели могут создавать объявления о товарах или услугах с фото, ценой и описанием.
*   **Безопасная сделка:** При покупке средства **замораживаются** на счету Покупателя.
    *   После получения товара/услуги Покупатель нажимает "Завершить сделку", и средства переводятся Продавцу.
    *   В случае спора любой участник может начать **Арбитраж**.
*   **Арбитраж:** Администратор рассматривает спор и принимает решение о переводе средств Продавцу или возврате Покупателю.

### 4. Система репутации
*   **Рейтинг:** Числовой показатель, который может меняться Администратором при разрешении жалоб.
*   **Статус аккаунта:** "Надежный", "Подозрительный", "Критический". Устанавливается Администратором.
*   **Жалобы:** Пользователи могут пожаловаться на другого пользователя. Жалобы рассматриваются Администратором.

## 🛠️ Установка и запуск

### 1. Зависимости

Установите необходимые библиотеки:

```bash
pip3 install -r requirements.txt
```

### 2. Настройка

1.  Получите токен вашего бота у **@BotFather**.
2.  Создайте файл `.env` и добавьте токен:
    ```
    BOT_TOKEN=ВАШ_ТОКЕН_БОТА_ЗДЕСЬ
    OWNER_TELEGRAM_ID=ВАШ_ТЕЛЕГРАМ_ID_ЧИСЛОМ
    ```
    *   `OWNER_TELEGRAM_ID` - ваш личный ID в Telegram, который будет автоматически назначен **Владельцем**.

### 3. Инициализация Владельца

Запустите скрипт для регистрации себя как Владельца:

```bash
python3 init_owner.py
```

### 4. Запуск

Запустите основной файл бота:

```bash
python3 bot.py
```

**Для постоянной работы бота на хостинге, пожалуйста, ознакомьтесь с подробной инструкцией в файле `HOSTING.md`.**

## ⚙️ Технические детали

*   **Язык:** Python
*   **Библиотека:** `python-telegram-bot`
*   **База данных:** SQLite (файл `bot_database.db`)
*   **Состояния:** Используются `ConversationHandler` для сложных многошаговых процессов (пополнение, создание объявления, арбитраж).
*   **Роли:** Роли хранятся в базе данных и определяют доступный функционал (клавиатуру).
