# Инструкция по развертыванию Telegram-бота "Рынок"

Этот бот разработан на Python с использованием библиотеки `python-telegram-bot` и базы данных SQLite. Для его стабильной работы требуется постоянное подключение к интернету, поэтому рекомендуется использовать **VPS/VDS** (виртуальный сервер).

## 1. Подготовка сервера (VPS/VDS)

Рекомендуется использовать операционную систему **Ubuntu 20.04/22.04** или аналогичный дистрибутив Linux.

### 1.1. Установка Python и зависимостей

Подключитесь к вашему серверу по SSH и выполните следующие команды:

```bash
# Обновление пакетов
sudo apt update
sudo apt upgrade -y

# Установка Python 3 и pip
sudo apt install python3 python3-pip -y

# Установка git (для клонирования проекта)
sudo apt install git -y
```

### 1.2. Клонирование проекта

Перейдите в домашнюю директорию и клонируйте проект (предполагается, что вы загрузили архив и распаковали его, или загрузите его напрямую):

```bash
# Создание директории проекта
mkdir telegram_bot_market
cd telegram_bot_market

# Если вы загрузили архив, распакуйте его здесь.
# Если вы загружаете файлы напрямую, пропустите этот шаг.

# Установка зависимостей
pip3 install -r requirements.txt
```

## 2. Настройка бота

### 2.1. Получение токена

1.  Откройте Telegram и найдите **@BotFather**.
2.  Создайте нового бота командой `/newbot`.
3.  Следуйте инструкциям и получите **токен** вашего бота (выглядит как `123456789:ABC-DEF123456...`).

### 2.2. Настройка файла `.env`

Создайте файл `.env` в корневой директории проекта (`/home/ubuntu/telegram_bot_market/`) и добавьте ваш токен:

```bash
nano .env
```

Содержимое файла `.env`:

```
# Токен вашего Telegram-бота, полученный от @BotFather
BOT_TOKEN=ВАШ_ТОКЕН_БОТА_ЗДЕСЬ
```

Сохраните и закройте файл (`Ctrl+O`, `Enter`, `Ctrl+X`).

## 3. Инициализация и первый запуск

### 3.1. Инициализация Владельца

Перед запуском основного бота необходимо инициализировать первого пользователя как **Владельца**.

1.  Узнайте свой Telegram ID (например, через бота `@userinfobot`).
2.  Запустите скрипт инициализации:

```bash
python3 init_owner.py
```

Скрипт попросит ввести ваш Telegram ID. После ввода вы будете зарегистрированы в базе данных как **Владелец**.

### 3.2. Запуск бота

Запустите основной файл бота:

```bash
python3 bot.py
```

Бот должен запуститься и начать работать.

## 4. Запуск в фоновом режиме (Рекомендуется)

Чтобы бот работал постоянно, даже после закрытия SSH-сессии, используйте менеджер процессов, например, **`screen`** или **`tmux`**, или системный сервис **`systemd`**.

### Вариант 1: Использование `screen` (Простой)

1.  Установите `screen`:
    ```bash
    sudo apt install screen -y
    ```
2.  Создайте новую сессию `screen`:
    ```bash
    screen -S market_bot
    ```
3.  Внутри новой сессии запустите бота:
    ```bash
    cd /home/ubuntu/telegram_bot_market
    python3 bot.py
    ```
4.  Отсоединитесь от сессии, нажав **`Ctrl+A`**, затем **`D`**. Бот продолжит работать в фоновом режиме.
5.  Чтобы вернуться к сессии, используйте:
    ```bash
    screen -r market_bot
    ```

### Вариант 2: Использование `systemd` (Профессиональный)

1.  Создайте файл сервиса `market_bot.service`:
    ```bash
    sudo nano /etc/systemd/system/market_bot.service
    ```

2.  Добавьте следующее содержимое (замените `/home/ubuntu/` на ваш реальный путь, если он отличается):

    ```ini
    [Unit]
    Description=Telegram Market Bot Service
    After=network.target

    [Service]
    User=ubuntu
    WorkingDirectory=/home/ubuntu/telegram_bot_market
    EnvironmentFile=/home/ubuntu/telegram_bot_market/.env
    ExecStart=/usr/bin/python3 /home/ubuntu/telegram_bot_market/bot.py
    Restart=always
    RestartSec=5

    [Install]
    WantedBy=multi-user.target
    ```

3.  Сохраните и закройте файл.

4.  Перезагрузите systemd и включите/запустите сервис:
    ```bash
    sudo systemctl daemon-reload
    sudo systemctl enable market_bot.service
    sudo systemctl start market_bot.service
    ```

5.  Проверьте статус бота:
    ```bash
    sudo systemctl status market_bot.service
    ```

Бот запущен и готов к работе!

## 5. Управление с телефона

Для управления ботом с телефона (перезапуск, просмотр логов) вам потребуется **SSH-клиент** (например, **Termius** или **JuiceSSH**).

1.  Установите SSH-клиент на ваш смартфон.
2.  Подключитесь к вашему VPS/VDS, используя IP-адрес, логин (`ubuntu` или ваш пользователь) и пароль/ключ.
3.  После подключения вы сможете выполнять команды, как если бы вы сидели за компьютером. Например, для просмотра логов systemd:
    ```bash
    sudo journalctl -u market_bot.service -f
    ```
